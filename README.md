## 🎯 Projetos Principais

### 1. **GiroMM** 📊
Multi-dashboard para visualização de métricas de produção e performance
- **Stack:** Flask | PostgreSQL | Python | JavaScript
- **Features:** Animações em tempo real, múltiplas visualizações, SFMM dashboard
- **Status:** ✅ Em produção

### 2. **Sell-Through Dashboard** 💹
Ferramenta web de análise de métricas varejistas
- **Stack:** Flask | PostgreSQL | SQL | Power BI
- **Features:** Dashboards interativos, análise de performance comercial
- **Status:** ✅ Em produção

### 3. **Boletim de KPIs** 📋
Sistema de gestão e boletim de KPIs para Controladoria Comercial
- **Stack:** Python | Power BI | Excel
- **Features:** Dashboard, jornal de KPIs, ferramenta de gestão
- **Status:** ✅ Em desenvolvimento ativo

### 4. **Automação SFMM** 🤖
Scripts de automação para processos internos
- **Stack:** Python | SQL | VBA
- **Features:** Processamento automático, relatórios agendados
- **Status:** ✅ Em produção

### 5. **Planilha de Controle** 📑
Sistema de gestão com Excel avançado e Python
- **Stack:** Excel | Python | Automação VBA
- **Features:** Rastreamento, cálculos automáticos
